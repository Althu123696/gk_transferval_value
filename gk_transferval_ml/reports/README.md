# GK TransferVal ML Project

Predicting goalkeeper market value using performance stats with machine learning.

## 🔍 Objective
Use regression models to estimate transfer market value based on metrics like clean sheets, saves, and age.

## 📁 Structure
- `data/`: Raw dataset
- `notebooks/`: EDA and ML modeling
- `models/`: Saved models
- `reports/`: Visuals and insights

## 🧠 Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn, GitHub

## 🚀 Status
Project initialized. EDA in progress.
